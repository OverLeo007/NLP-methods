# Лабораторная работа №3 — поиск документов с LSA и Word2Vec

Приложение обучает LSA и Word2Vec, сохраняет модели и ищет документы по текстовому
запросу. Команда `evaluate` сравнивает сохранённые модели по Recall@5 и MRR@10.

[Корневой README](../../readme.md) содержит список работ.
Методы и результаты приведены в [отчёте](Laba3.md).

## Быстрый старт

Подготовьте JDK 25 по [общей инструкции Java](../README.md). Используйте платформу
x86_64. Проверенное окружение — Windows 11 x86_64 и JDK 25.0.2.

Выполните команды из `java/` в Windows CMD. В PowerShell используйте
`./gradlew.bat` и `./run-lab.cmd`; в Linux/macOS — `sh ./gradlew` и
`sh ./run-lab.sh`. Остальные аргументы сохраните.

Укажите новый каталог `--output`. Существующий каталог не перезаписывается.

```bat
gradlew.bat :laba3:build :laba3:javadoc
run-lab.cmd laba3 train --algorithm word2vec --input laba3/examples/documents.csv --output laba3/artifacts/word2vec-demo --limit 3 --dimensions 8 --epochs 2 --min-count 1 --window 3 --workers 1
run-lab.cmd laba3 search --algorithm word2vec --model laba3/artifacts/word2vec-demo --query "Космос ракеты спутники космос ракеты спутники" --top 3
```

В проверенном запуске получены 3 документа, 18 токенов и словарь из 9 слов.
Покрытие запроса — 6/6. Порядок выдачи: `space` (cosine 1,000000),
`music` (0,672102), `sport` (0,394221).
Запрос повторяет текст документа. Пример проверяет сохранение и поиск после загрузки.

Сборка создаёт `laba3/build/libs/laba3-0.1.0.jar`.
Для развёртывания соберите JAR на целевой платформе: нативные CPU-библиотеки
выбираются при сборке.

## Использование

Добавьте `--help` к нужной команде, чтобы открыть справку:

```bat
run-lab.cmd laba3 --help
run-lab.cmd laba3 train --help
```

| Команда       | Обязательные параметры                                               | Результат                                                                   |
|---------------|----------------------------------------------------------------------|-----------------------------------------------------------------------------|
| `train`       | `--input FILE_OR_DIR --output DIR`                                   | Сохранённая модель и JSON со счётчиками и временем стадий.                  |
| `search`      | `--model DIR --query "текст"`                                        | JSON с покрытием запроса и найденными документами. Обучение не запускается. |
| `prepare-ria` | `--corpus ZIP_OR_JSONL --queries JSONL --qrels JSONL --output DIR`   | Общая коллекция, отложенные запросы, разметка и манифест.                   |
| `evaluate`    | `--collection DIR --lsa-model DIR --word2vec-model DIR --output DIR` | Краткая JSON-сводка и полный протокол `report.json`.                        |

Укажите у `search` тот же `--algorithm`, который использован при обучении.
Для вывода логов и прогресса добавьте `--verbose` или `-v` перед подкомандой
либо после неё. Без этого флага успешная команда выводит только результат в stdout.
Логи и ошибки направляются в stderr.

| Код завершения | Значение                       |
|----------------|--------------------------------|
| 0              | Команда выполнена.             |
| 1              | Ошибка выполнения.             |
| 2              | Ошибка разбора аргументов CLI. |

Для проверки нормализации запустите корневую команду с `--text`:

```bat
run-lab.cmd laba3 --text "Ёлками и машины НЕ были ни 12,5"
```

Результат: `елк`, `машин`, `не`, `ни`, `12,5` — по одному токену на строку.

### Параметры обучения и поиска

Все параметры таблицы необязательны.

| Параметр                    | Команда           | По умолчанию | Назначение                                                             |
|-----------------------------|-------------------|--------------|------------------------------------------------------------------------|
| `--algorithm word2vec\|lsa` | `train`, `search` | `word2vec`   | Выбор алгоритма.                                                       |
| `--limit N`                 | `train`           | 1000         | Максимальное число уникальных документов; `N >= 2`.                    |
| `--dimensions N`            | `train`           | 50           | Размер вектора Word2Vec (`N >= 2`) или число компонент LSA (`N >= 1`). |
| `--workers N`               | `train`           | 1            | Число потоков обучения и нативных вычислений; `N >= 1`.                |
| `--epochs N`                | `train`, Word2Vec | 3            | Число эпох; `N >= 1`.                                                  |
| `--min-count N`             | `train`, Word2Vec | 2            | Минимальная частота слова; `N >= 1`.                                   |
| `--window N`                | `train`, Word2Vec | 5            | Размер окна; `N >= 1`.                                                 |
| `--seed N`                  | `train`, Word2Vec | 42           | Начальное значение генератора случайных чисел.                         |
| `--max-features N`          | `train`, LSA      | 20000        | Максимальное число терминов словаря; `N >= 2`.                         |
| `--top N`                   | `search`          | 5            | Максимальное число результатов; `N >= 1`.                              |

Явные параметры другого алгоритма отклоняются.
Ограничения размеров приведены в [отдельном разделе](#ограничения).

### Входные данные

Передайте в `train --input` один из источников:

| Источник  | Требования и обработка                                                                                |
|-----------|-------------------------------------------------------------------------------------------------------|
| CSV       | UTF-8, обязательные столбцы `id,text`. Поля с запятыми и переносами строк заключите в кавычки.        |
| Папка TXT | Файлы читаются рекурсивно по порядку путей. Относительный путь становится ID, имя файла — заголовком. |
| JSONL РИА | Поля `_id,text,title`.                                                                                |
| ZIP РИА   | Внутри должна быть запись `corpus.jsonl`. Распаковка не требуется.                                    |

Обучение использует только текст документа. Поле `title` в CSV сохраняется
как метаданные. Дополнительные столбцы, включая `label,split`, допускаются,
но не задают разбиение для обучения и оценки.

Отбираются первые уникальные непустые документы до лимита. Пустые тексты,
повторы ID и текстов после [нормализации Unicode NFC](Laba3.md#31-данные-и-общая-подготовка)
пропускаются.
Счётчики описывают просмотренную часть источника.
Небольшие CSV-примеры включены в [examples/](examples/).
Исходные наборы данных и обученные модели в поставку не входят.

### Пример LSA

Запустите обучение и поиск на шести связанных документах:

```bat
run-lab.cmd laba3 train --verbose --algorithm lsa --input laba3/examples/related-documents.csv --output laba3/artifacts/lsa-demo --limit 6 --dimensions 3 --workers 1
run-lab.cmd laba3 search --algorithm lsa --model laba3/artifacts/lsa-demo --query "Ракеты спутники" --top 3
```

В проверенном запуске получены 6 документов, 24 токена, 15 терминов и 3 компоненты.
Документов с нулевым вектором нет. Покрытие запроса — 2/2.
Первые результаты — `space-a` и `space-b`, cosine обоих равен 1,000000.
Сходство третьего результата имеет порядок численной погрешности.
Пример проверяет преобразование и загрузку модели.

### Подготовка и обучение на РИА

Для сравнения моделей нужны три части данных:

| Исходный файл      | Назначение                                                             |
|--------------------|------------------------------------------------------------------------|
| `corpus.jsonl.zip` | Статьи, на которых обучаются модели и среди которых выполняется поиск. |
| `queries.jsonl`    | Поисковые запросы для проверки качества.                               |
| `test.jsonl`       | Разметка: ID правильной статьи для каждого запроса.                    |

Команда `evaluate` выполняет запросы и сверяет найденные статьи с разметкой.
Так получены Recall@5 и MRR@10 в отчёте. Эти запросы называются отложенными:
они используются для проверки, а не для обучения и выбора параметров.

Скачайте `corpus.jsonl.zip`, `queries.jsonl` и `test.jsonl` из
[RIA News Retrieval](https://huggingface.co/datasets/ai-forever/ria-news-retrieval/tree/main/data)
в `java/datasets/`. Подготовьте общую коллекцию:

```bat
run-lab.cmd laba3 prepare-ria --verbose --corpus datasets/corpus.jsonl.zip --queries datasets/queries.jsonl --qrels datasets/test.jsonl --output laba3/artifacts/ria-evaluation --documents 10000 --query-count 500 --seed 42
```

Все необязательные параметры `prepare-ria` перечислены ниже.

| Параметр        | По умолчанию | Назначение                                         |
|-----------------|-------------:|----------------------------------------------------|
| `--documents`   |        10000 | Число уникальных непустых статей, не меньше 2.     |
| `--query-count` |          500 | Число пригодных оценочных запросов, не меньше 1.   |
| `--seed`        |           42 | Начальное значение генератора для отбора запросов. |

Результат содержит `corpus.csv`, `queries.jsonl`, `qrels.jsonl` и `manifest.json`.
Все положительно размеченные статьи выбранных запросов включаются в коллекцию.
Оставшиеся места занимают фоновые документы. Причины исключения запросов
записываются в `excludedQueries`. Если указанные размеры недостижимы,
команда завершится ошибкой до записи файлов.
Метод отбора описан в [отчёте](Laba3.md#31-данные-и-общая-подготовка).

Обучите обе модели на одном `corpus.csv`:

```bat
run-lab.cmd laba3 train --verbose --algorithm lsa --input laba3/artifacts/ria-evaluation/corpus.csv --output laba3/artifacts/ria-lsa-reference --limit 10000 --dimensions 100 --max-features 2000 --workers 1
run-lab.cmd laba3 train --verbose --algorithm word2vec --input laba3/artifacts/ria-evaluation/corpus.csv --output laba3/artifacts/ria-word2vec-reference --limit 10000 --dimensions 100 --epochs 10 --min-count 2 --window 5 --seed 42 --workers 1
```

Для повторения условия замеров `-Xmx4g` используйте
прямой вызов Java из [общей инструкции](../README.md).
Раннер использует стандартный размер heap JVM.

### Единая оценка

Передайте подготовленную коллекцию и обе сохранённые модели:

```bat
run-lab.cmd laba3 evaluate --verbose --collection laba3/artifacts/ria-evaluation --lsa-model laba3/artifacts/ria-lsa-reference --word2vec-model laba3/artifacts/ria-word2vec-reference --output laba3/artifacts/ria-comparison
```

Команда проверяет целостность файлов, состав коллекции и профиль нормализации.
Порядок ID, тексты и заголовки документов должны совпадать в коллекции и обеих моделях.
Для каждого запроса требуется положительная разметка.
Укажите модели, заранее обученные на `corpus.csv` этой коллекции.

При расчёте среднего значения метрики сумма вкладов делится на число всех выбранных запросов.
Пустые после нормализации запросы, OOV и запросы с нулевым вектором дают нулевой вклад.
Формулы и фактические результаты приведены в [отчёте](Laba3.md#36-оценка-качества-и-ограничения).

В `report.json` сохраняются состав коллекции, параметры и версии моделей,
время обучения, метрики, покрытие и статусы.
Протокол также содержит ID документов с нулевым вектором и время открытия и поиска.
Для каждого запроса записываются разметка, первые десять результатов и вклад в метрики.

### Вывод и перенос модели

Поле `seconds` результата `train` содержит стадии `preparation`, `training`,
`indexing` и `saving`. Поле `trainingSeconds` равно `seconds.training`.
Счётчики документов, токенов и терминов, фактическая размерность и число документов
с нулевым вектором выводятся вместе с каталогом модели.
[Границы замеров](Laba3.md#34-условия-и-границы-измерений) описаны в отчёте.

Результат `search` содержит `status`, `knownTokens`, `totalTokens` и `hits`.
Поля токенов считают вхождения после нормализации.
В `hits` указаны ID, заголовок, фрагмент и cosine. Равные сходства упорядочиваются по ID.

| `status`                    | Значение                                          |
|-----------------------------|---------------------------------------------------|
| `ok`                        | Поиск выполнен.                                   |
| `oov`                       | В запросе нет известных модели токенов.           |
| `empty_after_normalization` | После нормализации токенов не осталось.           |
| `zero_vector`               | Известные токены есть, но вектор запроса нулевой. |

Например, запрос `абракадабравыв` к модели РИА возвращает:

```json
{"status":"oov","knownTokens":0,"totalTokens":1,"hits":[]}
```

Для переноса скопируйте весь каталог модели:

| Алгоритм | Файлы                                           |
|----------|-------------------------------------------------|
| LSA      | `lsa.json.gz`, `manifest.json`.                 |
| Word2Vec | `vectors.txt`, `data.json.gz`, `manifest.json`. |

При загрузке проверяются целостность файлов, профиль нормализации и метаданные.
Индекс восстанавливается без обучения.


## Ограничения

- Для обучения нужны минимум два документа и два термина.
  Если порог частоты Word2Vec исключил словарь, стоит уменьшить `--min-count` до 1.
- Фактическое число компонент LSA ограничено числом документов минус один
  и числом терминов минус один. Матрица ограничена 20 000 000 ячеек:
  при превышении стоит уменьшить `--limit` или `--max-features`.
- Документы с нулевым вектором не включаются в выдачу.
  Высокий cosine не гарантирует релевантность.
- Документы и индекс размещаются в памяти целиком.
  Возобновление обучения из сохранённой модели не поддерживается.
