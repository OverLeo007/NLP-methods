# Практические работы на Java

Каталог предназначен для работ на Java. Первой планируется работа №3: семантический
анализатор с LSA и Word2Vec и/или Doc2Vec и сравнением методов обработки документов.

Реализация и инструкции сборки будут добавлены вместе с первым работающим инкрементом.
Материалы исходного анализатора находятся в [работе №2 на Python](../python/Laba2/README.md).
