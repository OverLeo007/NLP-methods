# Практические работы на Java

Для сборки и запуска требуется **JDK 25**. Gradle устанавливать отдельно не нужно:
Wrapper входит в репозиторий. При первой сборке нужен доступ к интернету для загрузки
Gradle и зависимостей.

## Сборка

Откройте терминал в каталоге `java/`.

Windows PowerShell:

```powershell
./gradlew.bat build
```

Linux/macOS:

```sh
sh ./gradlew build
```

Убедитесь, что `java -version` показывает Java 25. Если установлено несколько JDK,
выберите JDK 25 через `JAVA_HOME` и добавьте его `bin` в начало `PATH` текущего терминала.
